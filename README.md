# OS4P_Group11_Arduino
Open Science for Physicists Group 11 Arduino Project

## Workflow

1. Setup the Arduino software. Instructions are given in `Getting_started.pdf` in the instructions folder.
2. Build the breadboard circuit for the $\text{CO}_2$ sensor. Instructions are given in `CO2_sensor_setup.pdf` in the instructions folder.
3. Make sure that the SD card is cleared out before each run. The code for this is given in the `delete_sd.ino` file.
4. Run `CO2_Sensor_Inital.ino`.
