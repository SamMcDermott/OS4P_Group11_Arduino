# OS4P_Group11_Arduino
Open Science for Physicists Group 11 Arduino Project

## Workflow

1. Setup the Arduino software. Instructions are given in `Getting_started.pdf` in the instructions folder.
   
2. Build the breadboard circuit for the $\text{CO}_2$ sensor. Instructions are given in `CO2_sensor_setup.pdf` in the instructions folder.
   
3. Make sure that the SD card is cleared out before each run. The code for this is given in the `delete_sd.ino` file in the given_codes folder.
   
4. To run and plot the data the files `CO2_Sensor_Inital.ino`, `extract_data_from_csv.ino` and python files `plotting_code_CO2.py`, `save_serial_data.py` in the given_codes folder. Instructions are given in `Saving_data_from_sd.pdf` in the instructions folder.
